Theme WordPress modern untuk Hamago Pest Solutions (hamagopest.co.id). Fully responsive, animasi hero icon berputar (orbit radar), parallax smooth, font Sora + Inter, dan sepuluh widget Elementor kustom "Hamago Elements" agar setiap section bisa diedit.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme → pilih hamagopest.zip → Install → Activate.
2. Settings → Reading → pilih static homepage (atau biarkan default demo).
3. Customize → Situs Identity → unggah logo.
4. Customize → "Hamago Pest — Pengaturan" → isi kontak & sosial media.
5. Install plugin Elementor → edit halaman dengan widget kategori "Hamago Elements".
